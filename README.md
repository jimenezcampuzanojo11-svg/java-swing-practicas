# ☕ Java Swing Prácticas

¡Bienvenido a mi repositorio de interfaces gráficas en Java! 
En este espacio comparto mi proceso de aprendizaje desarrollando aplicaciones de escritorio con la biblioteca 
**Java Swing**, programando cada componente de forma limpia mediante código puro.

## 📁 Estructura de las Prácticas

El repositorio está organizado con archivos numerados de forma cronológica para reflejar mi evolución:

*   **01 al 03 (Fundamentos de Swing):**
*   Primeros pasos con ventanas principales (JFrame),
*   contenedores y configuración básica de interfaces gráficas.
  
*   **04 al 06 (Componentes Interactivos):**
*   Manejo, personalización y posicionamiento de botones (JButton)
*   y etiquetas de título (JLabel).
  
*   **07 al 11 (Entrada de Datos y Selección):** Captura de texto a través de cuadros de texto (JTextField),
*   uso de combos de selección (JComboBox)
*   y ejercicios matemáticos como el cálculo del volumen de una esfera.
  
*   **12 al 17 (Aplicaciones Prácticas):**
*   Proyectos que integran lógica visual, incluyendo manipulación de colores,
*   barras de menú de navegación (JMenuBar), operaciones matemáticas de suma y
*   manejo de botones de opción (JRadioButton).

## 🛠️ Tecnologías y Herramientas
*   **Lenguaje:** Java 
*   **Biblioteca Gráfica:** Java Swing / AWT (Diseño construido 100% mediante código)
*   **IDE de Desarrollo:** NetBeans
